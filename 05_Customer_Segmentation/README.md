# Customer Segmentation Analysis

## 📊 Project Overview

This project presents a Customer Segmentation Analysis dashboard built using Power BI to analyze customer segments and identify high-value customer groups.

The dashboard provides insights into sales, profit, and regional performance to support data-driven business decisions.

## 🎯 Project Objectives

* Analyze sales performance across customer segments
* Identify high-value customer groups
* Compare profit contribution by customer segment
* Analyze regional performance
* Identify potential areas for business growth

## 🔍 Key Insights

* The Consumer segment generated the highest sales.
* Consumer customers contributed the highest profit.
* The Home Office segment showed lower revenue contribution.
* Regional analysis highlighted areas with potential for growth.

## 🛠️ Tools & Skills Used

* Power BI
* Data Visualization
* Business Analytics
* Customer Analytics
* Dashboard Design
* Data Analysis

## 📈 Dashboard

The interactive Power BI dashboard provides visual insights into customer segments, sales, profit, and regional performance.

## 💡 Business Value

Customer segmentation analysis helps businesses understand which customer groups contribute most to sales and profit and identify areas where additional growth opportunities may exist.

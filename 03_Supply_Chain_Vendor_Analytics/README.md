# Supply Chain & Vendor Analytics Dashboard

## 📊 Project Overview

This project presents a Supply Chain and Vendor Analytics Dashboard built using Power BI and Excel.

The dashboard analyzes supplier performance, revenue, stock levels, defect rates, manufacturing costs, transportation modes, and shipping efficiency to support data-driven supply chain decisions.

## 🎯 Project Objectives

- Analyze total revenue generated
- Track supplier-wise performance
- Monitor product defect rates
- Analyze stock levels
- Evaluate manufacturing costs
- Analyze transportation and shipping performance
- Present supply chain KPIs through interactive visualizations

## 🔍 Key Analysis

- Transportation Mode Analysis
- Shipping Efficiency Analysis

## 📈 Dashboard

The interactive Power BI dashboard provides visual insights into supplier performance, revenue, inventory, quality, manufacturing costs, and shipping operations.

## 💡 Business Value

The analysis helps identify supplier performance patterns, monitor operational KPIs, understand inventory and quality metrics, and support data-driven supply chain decision-making.

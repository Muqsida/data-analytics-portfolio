# Sales Analytics Dashboard

## 📊 Project Overview

This project presents an interactive Sales Analytics Dashboard built using Power BI to analyze sales performance across regions, product categories, and customer segments.

The dashboard uses KPIs and interactive visualizations to help understand sales and profitability patterns.

## 🎯 Project Objectives

* Analyze overall sales performance
* Compare sales across regions
* Analyze sales by product category
* Compare sales across customer segments
* Analyze profit by region
* Provide interactive filtering for regional analysis

## 🔍 Key Analysis

* Total Sales KPI
* Sales by Region
* Sales by Category
* Sales by Customer Segment
* Profit by Region
* Interactive Region Filter

## 🛠️ Tools & Skills Used

* Power BI
* Data Visualization
* Business Analytics
* KPI Tracking
* Dashboard Design
* Data Storytelling

## 📈 Dashboard

The interactive Power BI dashboard provides visual insights into sales performance, regional trends, product categories, customer segments, and profitability.

## 💡 Business Value

The dashboard helps users understand sales performance across different business dimensions and supports data-driven analysis of regional, category, and customer-segment performance.

This project strengthened my skills in dashboard creation, KPI tracking, data visualization, and data storytelling.

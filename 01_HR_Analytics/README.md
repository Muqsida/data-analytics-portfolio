# HR Analytics Dashboard

## 📊 Project Overview

This project presents an HR Analytics Dashboard built using Power BI to analyze workforce data and employee attrition.

The dashboard helps identify patterns related to employee turnover, job roles, age groups, salary, departments, and overtime.

## 🎯 Project Objectives

- Analyze employee attrition across different departments
- Understand attrition trends by job role
- Analyze employee age group distribution
- Compare salary across different job roles
- Examine the relationship between overtime and employee attrition
- Present HR insights through interactive data visualizations

## 🔍 Key Insights

- Department-wise attrition analysis
- Job role turnover trends
- Employee age group distribution
- Salary analysis across job roles
- Overtime and attrition relationship

## 🛠️ Tools & Skills Used

- Power BI
- Data Visualization
- HR Analytics
- Dashboard Development
- Analytical Thinking

## 📈 Dashboard

The Power BI dashboard provides visual insights into employee attrition and workforce patterns.
